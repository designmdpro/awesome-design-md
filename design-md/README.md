# DESIGN.md Files

30 complete DESIGN.md files extracted from real production websites. Copy one into your project root and ask your coding agent to follow it.

These files are synced weekly from the free tier of [DesignMD Pro](https://www.designmdpro.app), where each one also has a visual preview, revision history and CSS, Tailwind and shadcn exports. Please do not edit them here: open an issue instead.

```sh
curl -o DESIGN.md https://raw.githubusercontent.com/designmdpro/awesome-design-md/main/design-md/linear/DESIGN.md
```
